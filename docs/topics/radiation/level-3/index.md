# Level 3: Atoms

*Radiation and the atom · level 3 of 8 · rough age 9-10 (a guide for parents; anyone can start anywhere)*

The tiny pieces everything is made of are atoms. There are only about a hundred kinds, the elements, and they join up
to make everything else. This level meets atoms, elements and the periodic table, sees how atoms join into compounds,
and finds out how scientists discovered an element in the Sun before anyone found it on Earth. It ends with the elements
in Mars rock.
