# Gravity and orbits

Drop a cup and it falls. The same pull keeps the Moon going round the Earth, the Earth round the Sun, and decides
how a ship gets to Mars. This topic starts with things falling down and climbs, level by level, to Newton's law of
gravity, orbits, escape speed and the half-ellipse path that takes 259 days to reach Mars.

On Mars, gravity is a little over a third of Earth's. That one number changes how you walk, jump, build and launch,
and it comes back in almost every lesson here.
