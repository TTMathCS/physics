# Level 5: Measuring the sky

*Space and time · level 5 of 8 · rough age 12-13 (a guide for parents; anyone can start anywhere)*

Nobody has stretched a tape measure to the Sun. Every distance in space was worked out from angles, timing and a little
geometry. This level measures angles in the sky, turns them into sizes and distances, and ends with how big Mars looks
from Earth, and why it changes so much.

| --- | --- |
| [Angles in the sky](01-angles-in-the-sky.md) | Use degrees, arcminutes and arcseconds to describe the sky |
| [Angular size](02-angular-size.md) | Link how big something looks to its real size and distance |
| [Parallax](03-parallax.md) | Find a distance from the shift seen from two places |
| [The astronomical unit](04-the-astronomical-unit.md) | Use Kepler's third law to find planet distances in au |
| [Light-minutes and light-years](05-light-minutes-and-light-years.md) | Measure distance by the time light takes |
| [How big Mars looks](06-how-big-mars-looks.md) | Work out the size of Mars in the sky, and why it changes |
