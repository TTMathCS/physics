# Level 3: How fast is light?

*Space and time · level 3 of 8 · rough age 9-10 (a guide for parents; anyone can start anywhere)*

Light is the fastest thing there is, but it still takes time to travel. This level times it: a second and a bit from
the Moon, eight minutes from the Sun, and anywhere from 3 to 22 minutes from Mars. It ends at the controls of a rover,
where every command arrives minutes after it is sent.
