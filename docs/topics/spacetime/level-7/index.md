# Level 7: Special relativity

*Space and time · level 7 of 8 · rough age 15-16 (a guide for parents; anyone can start anywhere)*

Light travels at the same speed for everyone, however fast they move. That one fact, which Einstein took seriously in
1905, means moving clocks run slow and moving lengths shrink. This level builds the rules from a clock made of light,
checks them with muons from the sky, and ends with the clocks on a trip to Mars.
