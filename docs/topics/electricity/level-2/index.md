# Level 2: Circuits

*Electricity and magnetism · level 2 of 8 · rough age 7-8 (a guide for parents; anyone can start anywhere)*

A circuit is a loop with no gaps. This level builds circuits with switches, tests which things let electricity through,
and draws circuits with symbols the way engineers do. It ends with the circuits inside a Mars rover, from its power
source to its wheels.
