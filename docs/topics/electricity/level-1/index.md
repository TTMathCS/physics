# Level 1: Magnets and batteries

*Electricity and magnetism · level 1 of 8 · rough age 5-6 (a guide for parents; anyone can start anywhere)*

Magnets pull on some things and not others, and two magnets can pull together or push apart. A battery can light a bulb,
but only if the wires go all the way round. This first level plays with both. At the end you find out why a compass
would not help you on Mars, and why the dust there sticks to magnets.
