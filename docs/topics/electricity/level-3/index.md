# Level 3: Static and current

*Electricity and magnetism · level 3 of 8 · rough age 9-10 (a guide for parents; anyone can start anywhere)*

Rub a balloon on your hair and it sticks to the wall. That is static electricity: charge that has built up and stays
put. When charge moves, it is a current. This level meets both, from crackling jumpers to lightning, and ends with the
tiny sparks a rover heard crackling in the dust devils of Mars.
