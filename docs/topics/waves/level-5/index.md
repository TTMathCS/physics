# Level 5: Wave speed

*Waves, sound and light · level 5 of 8 · rough age 12-13 (a guide for parents; anyone can start anywhere)*

Every wave, from a ripple to a radio signal, follows the same rules. This level names the parts of a wave and uses the
wave equation $v = f\lambda$. You time light on its way to Mars, bounce waves off things to measure distance, bend light
as it slows down, and hear the pitch of a moving source change.
